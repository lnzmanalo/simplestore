# SimpleStore

A tiny e-commerce store built with pure HTML, CSS, and JavaScript.

No frameworks. No backend. No database. Just a working shopping cart in the browser.

## Features

- Product grid with emoji, name, price, and description
- Add items to cart
- Adjust item quantity (+ / −)
- Remove items from cart
- Live cart total and item count
- Checkout button (simulated order)
- Toast notifications for every action
- Responsive layout (cart moves below products on small screens)

## Demo

Open `index.html` in your browser — that's it.
